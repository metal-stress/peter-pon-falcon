# Peter-Pon for the FALC ON SoC: the website

The landing page of Peter-Pon, modern OpenWrt firmware for GPON SFP sticks built on the Lantiq FALC ON SoC (the Huawei MA5671A and its siblings).

**Live:** https://metal-stress.github.io/peter-pon-falcon/

The firmware's source code lives in [metal-stress/peter-pon-openwrt-falcon](https://github.com/metal-stress/peter-pon-openwrt-falcon).
